## Recommended native-resolution workflow (free tools; no paid credits)
Key facts: the supplied art is one 1774x887 composite split into four ~443 px-wide panels, so each view has only ~865 px of height. Any pipeline that starts from those crops cannot reach a 2000 px figure without invention. The fix is to **start each view at higher resolution**, not to enlarge.
1. **Generate/paint each view as its own image, not as four panels in one composite.** One view per image, full figure inside the frame with >= 8% empty margin on every side (no cropping at the hem), flat solid #00FF00 background, no frame lines/text, **the largest portrait size the generator allows** (ask for at least 1152 x 2304; if the generator caps lower, note the real pixel size). Use the approved Echo V2 images as the reference and `ECHO_V2_DESIGN_AUTHORITY.md` + `ART_BRIEFS.md` brief A as the prompt. ChatGPT image generation under the owner's own subscription is not my credits; I do not call paid tools. Record tool, date, prompt, seed in PROVENANCE.md.
2. **If the generator's maximum is below the needed detail,** use a *disclosed, assisted* path instead of pretending: (a) a free local anime upscaler (Real-ESRGAN anime model through Upscayl, or waifu2x; free, run on the owner's/artist's PC, GPU strongly preferred; none is installed in this sandbox: no GPU, no torch/OpenCV/rembg, only numpy/Pillow/onnxruntime/ImageMagick) from a >= ~1.4x smaller true render, then (b) a **manual paint-over in Krita or GIMP (free)** to re-ink the lines, fix hands/face/eyes and restore the hem at 1152x2304, then (c) side-by-side comparison against the approved art. Label such files "assisted-native" in PROVENANCE.md; the owner decides whether that meets "native". This is a human-in-the-loop route, not automatic enlargement.
3. **Best quality route (recommended if the generator cannot output >= ~1600 px tall):** a human illustrator (or the owner) paints/inks Echo V2 over the approved art directly on a 2304 x 4608 working canvas in Krita (free, layers, vector line tools, pressure brush), then exports 1152 x 2304 (2x supersampled -> crisp native lines). The layered Krita file doubles as the **rig part source** (parts as separate layers), which removes the later cutting step.
4. **Matte:** render/paint on flat #00FF00 or a dedicated transparent layer; remove the key with Krita/GIMP (select by colour + feather 0-1 px + de-spill), or with the free `rembg` (ISNet-anime) on the artist's machine; then run a lossless finishing pass: clamp interior alpha >= 250 to 255, remove stray specks, place on the 1152 x 2304 canvas with the foot-midpoint at x=576 and soles at y=2176 by **translation only**. I can write that finishing script (Pillow, refuses to scale) when a true native source exists.
5. **Check, then approve:** run `tools/check_hero_turnaround.py` on the four native files + two detail sheets, build `tools/make_echo_review_sheet.py` side-by-side sheets, owner approves before any rigging.
Not recommended: enlarging the existing crops (blur, no recovered detail); vectorising/tracing the crops (loses shading); a 3D proxy model of Echo (a new character asset, risk of identity drift); any procedural redraw.
