# Browser QA harness (Chromium via Playwright, real web export)
Not part of the game build (`tools/*` is excluded from exports). Paths in the scripts are the ones used in the cloud sandbox; adjust them.
- `main_qa_hook.gd.txt`: copy over `scripts/ui/main.gd` in a THROWAWAY copy of the project; it publishes game state to `window.__qa` (scene, step, wave/phase, HUD rects, rewards). Never commit it over main.gd.
- `profile_ep2_seed.gd.txt` / `profile_ep1_seed.gd.txt`: copy over `scripts/core/profile.gd` in the throwaway copy to start from a seeded save (Episode 2 mid-quest / fresh Episode 1 at level 4).
- `rc21.cjs`: Episode 2 end-to-end (keyboard or touch at any viewport) with overlap sampler, MEND, rewards, energy checks. `perf.cjs`: same plus boot time, process RSS and frame-time stats. `e1b.cjs`: Episode 1 end-to-end. `web_matrix.sh`: builds lossless / S3TC-only / ETC2-only exports and runs the matrix.
- Software GL (SwiftShader) is used, so frame times/RSS are NOT representative of real GPUs.
- `ep3_browser.cjs`: Episode 3 end-to-end against the **"Web QA" export preset only** (`godot --headless --export-release "Web QA" build/web_qa/index.html`, served locally; never published). Keyboard or touch at any viewport, real input only; reads `window.__qa` from `scripts/qa/qa_hook.gd`. Checks the save/reload checkpoint (waits for the IndexedDB write to land first), all five puzzles, the Warden, rewards, teaser and home. `PORT=8801 node tools/qa/ep3_browser.cjs OUTDIR key|touch W H TAG`. Production "Web" has no QA button, banner or hook (see `tools/test_release_gate.py`).

Overnight additions (Web QA export only; see docs/overnight/):
- `motion_browser.cjs` (EP=1|3) + `motion_report.py [--table before after]`: per-frame positions and frame pacing while walking; `motion_chart.py` draws the comparison.
- `idle_footage.cjs` (EP=1|2|3, `DPR`, `WALK=1`, `TRANS=1`, `ZONE=<id>`) records real video of standing/walking/turning; `idle_report.py` measures stillness (deviation from the average picture, frame-to-frame change, sprite-frame changes per second) and builds side-by-side GIFs. The hook probe (`scripts/qa/qa_hook.gd`) adds `window.__qa_tr`, a `zone:<id>` command and the F3 frame-time overlay.
- `stuck_input.cjs` (touch cancel, focus loss), `resize_check.cjs`, `console_audit.cjs` (every console message type), `memory_soak.cjs` (RSS and JS heap), `cost_browser.cjs` (hide scene groups, compare frame time).
- Headless: `measure_walk_speed.gd` (speeds before/after on any commit), `script_cost.gd` (per-node `_process` cost), `cpu_frame_cost.gd` / `draw_cost.gd` (headless limiter caps them at ~145 fps: they cannot resolve draw cost; script cost is 34 us per frame).
